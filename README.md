# 30-Day Guide Landing Page

This is the landing page for the Remote Career System 30-Day Guide. 

## Tech Stack
- React
- Vite
- Tailwind CSS

## How to Run Locally

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```

3. Open the link provided in your terminal (usually `http://localhost:5173`) to view the site.

## Deployment
This project can be easily deployed to platforms like Vercel, Netlify, or GitHub Pages. Just connect the repository and use the build command:
```bash
npm run build
```
